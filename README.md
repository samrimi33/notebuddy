## 🌟 What's inside?

| Feature | What you can do |
|---|---|
| 📝 **Notes** | Create notes, checklists, folders, tags, linked notes, scanned notes, dictated notes, flashcards, and more. |
| 📖 **Diary** | Write diary entries, save photo memories, create postcards and time capsules, record voice diaries, and reflect weekly. Read diary entries in a book-style interface with page turns or export them as PDFs. |
| ✅ **Planning** | Manage tasks, habits, reminders, timetables, countdowns, meal plans, packing lists, and events. |
| 💸 **Money** | Track income and expenses, budgets, recurring bills, split bills, debts, savings goals, warranties, and monthly reports. |
| 💧 **Health** | Track water, sleep, periods, medication reminders, gratitude, and birthdays. |
| 🔐 **Secure vault** | Store passwords, payment cards, Wi-Fi details, and keys. Supported features include encrypted storage, authenticator codes, imports, and autofill. |
| 🛒 **Shared grocery lists** | Organize shopping lists with family members using supported live-sharing functionality. |
| ☁️ **Backup and restore** | Create encrypted backups and optionally use your own Google Drive for backup and restoration. |
| 🐧 **Buddy** | Spend time with your penguin companion, play games, collect badges, and explore festival outfits. |
| 📱 **Home-screen widgets** | Access supported widgets for tasks, groceries, habits, timetables, countdowns, search, and more. |

## 🔒 Privacy is a core feature

Your personal information deserves more than a privacy promise.

NoteBuddy is designed around local-first storage and user-controlled access.

- **Your data stays on your phone** for core local features.
- **No ads, no analytics, and no selling personal data**, as stated by the project.
- **App lock** with supported PIN, password, or biometric authentication.
- **Protected information** using encryption for supported locked notes and vault records.
- **Encrypted backups** protected by a password you choose.
- **Optional Google sign-in** for supported backup features.
- **Data portability** so you can move your information when changing devices.

Some features, including shared lists and Google Drive backup, require external services or connectivity. Review the privacy policy for details about the information involved in those features.

### 🔐 Security matters

NoteBuddy includes security-sensitive functionality such as password storage, autofill, backup encryption, and optional SMS-based imports. These features should be implemented and tested carefully.

Use a strong device lock, keep your backups safe, and never share your vault or backup password.

## 📲 Install on Android

**[Download the latest release →](https://github.com/samrimi33/notebuddy/releases/latest)**

1. Open the latest release page on your Android device.
2. Download `NoteBuddy.apk` from the release assets.
3. Open the downloaded APK.
4. If Android asks, allow your browser or file manager to install apps from that source.
5. Follow the installation prompts.

Only download and install APKs from sources you trust.

### 🛡️ About Android security warnings

Android may show additional warnings when an app is installed outside Google Play, particularly when it requests sensitive permissions.

A warning does not by itself prove that an app is malicious, but it should not be ignored either. Review the requested permissions, verify that the APK came from the official release, and follow the project's installation guidance before proceeding.

See the [installation help page](https://samrimi33.github.io/notebuddy/install-help.html) for additional instructions and the published signing-certificate fingerprint.

### 🔄 Updating NoteBuddy

Open **Settings → About** to check for updates, where supported.

When installing a newer version, use the same official signing identity. Android normally installs compatible updates over the existing app while preserving its data.

If an upgrade requires a fresh installation, export your data first and follow the migration instructions for that version. Never uninstall an existing installation before confirming that your backup can be restored.

## 🗺️ Project philosophy

NoteBuddy is built around four principles:

**Privacy.** Personal information should remain under your control.

**Simplicity.** Everyday tools should be easy to find and use.

**Ownership.** Your notes, memories, and records should be portable.

**Personality.** Useful software can be functional without feeling cold or impersonal.

The goal is to bring the convenience of several everyday tools into one thoughtful Android experience without relying on advertising to make the product useful.
