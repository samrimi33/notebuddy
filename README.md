# 🐧 NoteBuddy

**Your private notebook and life organiser — with a little penguin friend.**

Notes, diary, tasks, money, health and a password vault in one beautiful app.
Everything stays on your phone. No ads. No tracking.

## ✨ What's inside

| | |
|---|---|
| 📝 **Notes** | Checklists, folders, tags, linked notes with a note map, scanning, dictation, read aloud, flashcards, version history |
| 📖 **Diary** | Lined notebook pages, photo memories, postcards, time capsules, voice diary, weekly reflection — read it as a real book with page turns, or save it as a PDF to print |
| ✅ **Plan** | Tasks, habits, reminders, timetable, countdowns, meal planner, packing lists, event planner |
| 💸 **Money** | Expenses and income, budgets, recurring bills, split bills, debts, savings jars, warranties, monthly PDF reports |
| 💧 **Health** | Water, sleep and period tracking, medicine reminders, gratitude jar, birthdays |
| 🔐 **Vault** | Passwords, cards, Wi-Fi and keys encrypted with AES-256 — import from Chrome, Bitwarden and more, 2FA codes, and autofill in other apps |
| 👨‍👩‍👧 **Shared lists** | Grocery lists the whole family can edit live — end-to-end encrypted |
| ☁️ **Backup** | Encrypted daily backup to your own Google Drive, restore on a new phone |
| 🐧 **Buddy** | A penguin friend with games, badges and festival outfits |
| 📱 **Widgets** | Today, grocery, habits, timetable, countdown, search and more on your home screen |

## 🔒 Private by design

- Your notes live **on your phone**, not on a server.
- Locked notes and the vault are **encrypted** with a key kept in your phone's secure hardware.
- App lock with **PIN, password or fingerprint**.
- Backups you export are **encrypted** with a password you choose.
- **No ads, no analytics, no selling data.** Google sign-in is optional.

## 📲 Install (Android)

1. Open the [latest release](https://github.com/samrimi33/notebuddy/releases/latest) on your phone.
2. Tap **NoteBuddy.apk** to download it.
3. Open the file and tap **Install**. If asked, allow your browser to install apps.

NoteBuddy tells you when a new version is ready (**Settings → About**). Updates install over the top and keep all your data.

> **Updating from 1.0.x?** If Android says the app isn't compatible: in the old app go to **Settings → Import & Export → Export Everything**, uninstall it, install the new version and restore your backup. This happens only once.
